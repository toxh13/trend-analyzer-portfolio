# ADR-0001. 서버 없이 GitHub Actions + Pages로 운영한다

- 상태: 제안 (2026-10-24)
- 결정: 수집·집계·배포를 GitHub Actions 예약 실행과 GitHub Pages로 옮기고, 상시 서버를 두지 않는다.

## 배경

v1은 OCI 무료 VM에서 Docker Compose(수집기·Spring·React·Oracle)로 운영했다. VM이 중지되자 포트폴리오에서 볼 수 있는 결과물이 캡처 이미지만 남았다. 데이터량은 3시간에 최대 50건으로 작고, 사용자는 조회만 한다.

## 검토한 대안

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| OCI VM 재가동 | v1 코드 그대로 | 무료 자원 회수·장애 시 다시 중지될 위험, 운영 부담 |
| Cloud Run·Lambda + 관리형 DB | 서버 관리 적음 | 무료 한도 관리, DB 비용, 계정·비밀값 관리 |
| **GitHub Actions + Pages** | 공개 저장소 무료, 실행 이력·로그 공개, 저장소 하나로 완결 | 예약 실행 지연, 60일 무활동 비활성화, 실시간 불가 |

## 결과

- 운영 비용 0원, 비밀값 없음(뉴스 RSS·HTML만 사용).
- 신선도 기준은 실시간이 아니라 6시간으로 둔다. 화면에 `meta.json`의 기준 시각과 신선도를 표시한다.
- 로그인·구독·Discord처럼 서버가 필요한 기능은 v2 범위에서 뺀다.
