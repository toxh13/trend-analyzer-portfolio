## 라이브 서비스

- 트렌드 대시보드
- 카테고리 분석
- 키워드 비교
- 관련 기사 탐색

순위와 건수는 수집 시점에 따라 달라집니다. 관리자 기능은 권한이 필요한 내부 운영 영역이므로 공개 문서에서는 구조와 설계 의도만 설명합니다.

## 문서의 상태 표기

| 표기 | 의미 |
| --- | --- |
| 구현 | 현재 코드 경로가 존재합니다. |
| 자동 검증 | 테스트 또는 빌드로 재현했습니다. |
| 로컬 검증 | 로컬 DB·브라우저·Docker에서 확인했습니다. |
| 운영 검증 | OCI 배포 환경에서 실제 데이터로 확인했습니다. |
| 예정 | 코드와 검증이 아직 없습니다. |

구현됐다는 사실만으로 운영 검증까지 끝났다고 표현하지 않습니다.
